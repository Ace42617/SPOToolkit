## Historical: SPO Toolkit Alpha 1.0

Early alpha packaging notes for the Chrome/Edge extension: export list/library data, run reports, manage views, and quick links on SharePoint.

## Installation

1. Open **edge://extensions** or **chrome://extensions**
2. Enable **Developer mode**
3. Click **Load unpacked** and select the folder containing the extension files (the folder that contains `manifest.json`, `popup.html`, etc.)

**If you downloaded the .zip:** unzip it first, then select the unzipped folder in step 3.

## What's included

- **Quick links** – Site settings, Recycle bin, Admin center, and more
- **Page Properties** – View/copy `_spPageContextInfo` from the current page
- **Columns** – Browse list columns (when on a list/library page)
- **Views** – Edit or create list views (columns, sort, filter, group by)
- **Reports** – Download list contents (CSV/Excel), folder count, path lengths, permissions, permissions matrix
